# Против Течения - порт телеигры с РТС.Медиа
Ну это самое, билдить  в Visual Studio 2008. А для запуска надо чтобы у вас в системе был поставлен .Net Framework 3.5!  
# Как создавать свои вопросы?
Открываете ProtivTecheniya.Studio.exe, затем указываете путь к файлу questions.txt, и дальше вводите вопрос, неправильный и правильные ответы.
